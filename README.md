# ros_snapd_interfaces

Interface definitions for https://github.com/canonical/ros_snapd.

This repository provides ROS 1 (Noetic) service definitions intended to interact with the following snapd bridge:

- https://snapcraft.io/ros-snapd

ROS 1 interface definitions are available on the `ros` branch of this repository, and ROS 2 interface definitions are available on the default `ros2` branch.
